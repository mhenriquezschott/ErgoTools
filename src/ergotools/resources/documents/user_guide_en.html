ErgoTools User Guide

Linux · 2026-11-04

One main Save writes the entire project: workers, organization, Jobs, assignments, assessments, PLOT and complete JROT schemes. Closing an editor retains accepted changes without writing the project file. Project close or switching offers Save/Discard/Cancel. Main and editor Undo/Redo buttons share one chronological history. Removing records through replay requires confirmation; restoring records, ordinary edits and navigation do not. Text fields keep native typing Undo. Start the integrated application

On this Linux development installation, run bash tools/run.sh (installed: ergotools) from the new project folder. This opens the integrated LiFFT, DUET, Shoulder Tool (ST), PLOT and JROT application with the 3D avatar. --disable-vtk is for renderer-free diagnostics only.

Use the window normally and enlarge it when needed. English and Spanish are available in Tools > Settings. Apply accepts settings; application preferences are shared immediately. Project display precision/default units are written by the main Save. Existing scientific values are never rounded by display changes. Task counts are local to the selected worker/tool/context and undoable.

Help → About shows the ErgoTools developer and original-tool credits. Help → About JROT lists the historical research contributors to Job Rotation Optimization.

Projects and original-project conversion

New starts a project; Save gives an unsaved project its own .ergprj file. Open automatically loads an available assessment from the selected project. Recent projects is a shortcut to the same Open workflow. Entries display full file paths so identical filenames in different folders are distinguishable; hover retains the full literal path. Properties shows the open project metadata.

Earlier projects need an upgrade. Open explains the change, offers Migrate/Cancel and shows a copyable command for the separate migration tool. Keep the original database/data and image folders beside the descriptor until conversion succeeds. The original files remain unchanged. Conversion refreshes calculations from saved inputs and embeds all plant images in a new native project; it does not retain a duplicate original-result archive.

The upgraded copy opens temporarily. Use Save, choose a new .ergprj file and confirm the prefilled details before closing; after saving, no original folders or converter are needed. Cancelled or failed Save retains the temporary copy for retry. Closing asks Save/Discard/Cancel even when the assessment is clean. Temporary paths do not enter Recent Projects. Save first to enable the ordinary management/PLOT/JROT/export workflow. Missing tools/assets or unsupported data show an error and retain the current project.

Save As validates and publishes all accepted project content to another file, leaving the original unchanged. Backup copies the last main-Save baseline without switching the open project. Use the main Save first if the backup must include the latest accepted edits. Neither backup nor project files contain Undo history.

Workers, organization, jobs and assessment context

Workers creates and edits worker records. Worker ID is required; optional identity, employment and cm/kg or in/lb measurements are under Optional details. Add worker accepts one record and starts the next entry. Selecting another worker or closing the window retains valid edits in the open project. Invalid entries remain available for correction or Cancel. A blank birth-date calendar opens eighteen years before today without assigning a birthday. The worker window shares the main Undo/Redo history: four additions undo W04, then W03, individually. Only the main Save writes the project file.

Workplace > Organization maintains plant, section, line, station and independent shifts. Workplace > Jobs manages Job details, workplace availability and one current risk set per Job. Review and edit tasks in the tool tabs, or choose a direct result or independent copy. JROT uses current Job values and keeps worker/Job arrangements. Referenced records cannot be deleted arbitrarily.

The main Assessment group selects the worker’s saved plant/section/line/station/shift assessment for the active tool. An existing assessment keeps its original assignment after later reassignment: the old assessment remains a historical observation, while the new assignment can have its own assessment. Saving never replaces assessments belonging to another tool or assignment.

The worker selector, ordering, first/previous/next/last, Workers, Search and Transfer share the top worker row; surname letters remain beneath the selector. Standalone assessment and the current-selection summary are inside this worker area. Assessment reveals a compact full-width group beneath the alphabet, inside the same frame. Standalone is at the right of the worker selector row; the Assessment disclosure and selection summary share the compact row beneath. Explicit toggles animate without moving or rebuilding the alphabet/status row; initial project restoration settles immediately. It starts hidden when no visibility choice has been saved; main Save retains an explicit expanded/collapsed choice. Worker navigation opens the active tool’s standalone assessment first. If none exists, it opens the first saved workplace assessment alphabetically by Plant, Section, Line, Station and Shift; if no source exists, it shows a clearly labeled standalone preview without creating data. Plant, Section, Line, Station and Shift list only this worker’s saved assessments for the active tool and cascade to relevant choices. Counts belong to headings, not saved names. Station shows the selected risk percentage and shared risk colors; other stations with varying results show a range, never an invented mean. Shift contains only its identity. Job has a separate information cell, becoming a selector only when multiple saved owners share a station and shift. A subtle outline marks the open workplace path or the Standalone button; the summary identifies the selection even while context is hidden. Available workplace assessments remain advertised when standalone is open. The browser does not filter workers, assign Jobs, create assessments or copy data. Transfer remains the explicit Copy/Move workflow.

Use Add assessment… at the right of the expanded Assessment group to choose a station and shift in the shared workplace hierarchy picker. A Job is optional. The current worker and tool are fixed by the main controls. An existing active workplace assignment is reused with its Job unchanged; otherwise the assignment is created with the blank assessment. If that assignment already has this tool's assessment, ErgoTools asks before replacing its task inputs/results; No is the default and keeps them intact. Yes opens a blank 15-task grid while retaining the assessment identity. New blank assessments can be saved empty and completed later. Main Save writes the project; shared Undo/Redo restores creation or replacement, including prior results. Standalone assessments and other tools are independent and remain unchanged.

Use Transfer to choose Copy or Move for selected assessment tools. Both standalone sources and workplace sources are supported. Choose the destination worker and either Standalone assessment or a station and shift in the dialog. Copy retains the source and creates independently editable data; Move removes the selected source only after the destination is created successfully. Existing selected destination tools require explicit replacement confirmation; other tools and historical observations remain. Tasks, units and matching calculated results retain their exact values. The operation is atomic and uses shared Undo/Redo; main Save publishes accepted changes. There is no separate Copy to workplaces command.

Switching tools, workers and assessment contexts retains accepted input and project history without a local Save prompt. Main Save/Save As include accepted edits from all editors. Only leaving the project asks Save/Discard/Cancel. Invalid unfinished numeric input must be corrected or cancelled before accepting that form. Last-used locations are personal settings; context visibility is a project preference.

Job details groups Add/Delete beside the metadata. Task tabs use the main tool icons; colored totals appear above Clear assessment/Calculate. The selected-tool sidebar groups its gauge, animated damage bar, assessment state and legend. Task inputs/Direct result are selectable buttons. Copy from worker and Copy from Job open searchable source browsers with ID/name navigation and surname/name initials. Worker contexts distinguish standalone and workplace assessments; colored previews show existing damage and probability. Cancel copies nothing. Shared Undo/Redo replaces a separate Discard changes action.

An empty Job tool in Task inputs mode shows one starter task. Use + Task and - Task to adjust rows; Undo restores removed inputs/results. Direct result mode has no task source. Valid complete inputs calculate automatically, and Calculate remains available. Numeric fields, descriptive selectors, column order, sticky headers, inline totals and the right-hand cards match the main assessment UI. Expand a source assessment/Job row to inspect its read-only tasks directly beneath it. Its alphabet fills the selector width and magnifies the hovered initial. Job Undo/Redo uses smaller main-style icon-and-caption buttons, with detailed action tooltips.

Use task checkboxes and All/None inside an expanded copy source to copy selected rows. Copying all tasks preserves exact results; a calculated subset is recalculated on Copy, including its contribution percentages. Uncalculated selections retain inputs only; blank unused rows are omitted. Source inputs/results are never changed. Job totals align with Damage; +/- Task sits between Clear and Calculate. Full tool titles match the main UI. Tool-tab changes participate in shared Undo/Redo without making project data unsaved.

In Direct result mode, edit the colored cumulative-damage cell beneath the grid; probability remains derived in the following row. There is no duplicate input form. Copy details use compact populated rows with original task numbers; All/None sits beside Task #. Blank unused rows are not offered for copying. Secondary windows share adjacent Undo/Redo icon-and-caption buttons; the main toolbar is unchanged.

Search opens Find Assessment across workers for the active tool. Filter by worker ID/name, surname initial or workplace, then choose Use assessment. Closing it leaves the current assessment unchanged.

LiFFT, DUET and Shoulder Tool

Choose the tool tab and enter its task inputs. LiFFT uses lever arm, load and repetitions; DUET uses OMNI-Res and repetitions; ST adds task direction. Follow the unit labels on the controls. Calculate evaluates entered tasks; Save stores the inputs and the calculated results. Calculate alone does not save them.

Wholly unused task rows are ignored and do not make an entered assessment incomplete. Started rows with missing required values remain incomplete and results include completed rows only. Empty or unavailable values are not proof of zero risk. Imported results appear as Recorded; saved fresh calculations retain their own status. Editing an input clears obsolete displayed results. Saved inputs and calculated results retain calculator precision. Project display defaults are one decimal for inputs, moments and probability, four for task/cumulative damage, and one for contribution percentages. Repetition counts display no decimals. Formatting and unit switches never round unchanged stored values.

Clear assessment replaces Reset and trash. After confirmation, it clears only the selected worker/tool/context inputs and results, keeping task count, units and ownership. Undo restores the previous inputs and results; Cancel preserves pending text. Main Save writes the cleared assessment. Other workers and tools are unchanged. Search finds saved standalone and workplace assessments for the active tool with colored risk values. Tools > Settings > Assessment identifies the project, worker, tool and workplace or standalone context. Select Change number of tasks on Apply: each assessment independently supports 1–100 rows, initially 15. Increasing appends empty rows; reducing keeps the first rows and confirms before removing entered trailing data. An unchanged count does nothing. Undo/Redo restores truncated data and matching results. Main Save writes accepted changes. ST preserves the original selector meanings and Tab order; this migration does not change scientific formulas.

In the main tools and Job Management, results update after a completed input edit (Enter, Tab or leaving the cell) when every started task is valid and complete. Blank unused rows are ignored. Incomplete or invalid started tasks clear automatic totals. Calculate remains available for explicit recalculation. Each accepted cell and its result share one Undo step; only the main Save writes the project.

Settings > Appearance > Animations groups independent avatar, risk-gauge and cumulative-damage animations. These are personal preferences; turning result animation off immediately displays its target without changing calculations.

Select task rows and import source rows

Click a task number, then Shift-click for a range or Ctrl-click for separate rows. − Task removes all selected rows together, after confirmation if any contains data. One Undo restores the batch. In Import task data, choose Header row and its number, then untick unwanted source rows. Include selected rows, Skip selected rows, Skip empty rows and Include all change only the temporary preview. Source files and column mappings remain intact.

Accepted pasted task names are immediately reusable throughout the project. Existing names are reused; new names, pasted inputs and automatic results share one Undo step. Undo asks for confirmation and restores previous data while removing only names created by that paste. Redo restores the same names and inputs. Previewing, skipped rows, unmapped name columns and Cancel create no names. Main Save stores the accepted changes.

Language, decimal marks and units

Settings supports English/Spanish, metric/imperial display and point/comma decimal input. Thousands grouping is unsupported. Existing assessment source units remain attached to their data; changing display units does not reinterpret saved numbers. Worker height/weight are displayed as cm/kg or in/lb and stored canonically as cm/kg.

CSV exports retain stable English column identifiers and point decimals regardless of interface language. Recorded unit labels and saved result precision are retained. PLOT coordinates are image pixels in either measurement system.

PLOT: filters, layout and charts

Open PLOT from the main toolbar. Select tool, workplace, risk view and optional demographic filters, then Apply filters. The map and worker/job/tool summaries use saved assessments and approved job-risk data. Inspect Individual, Job and Comparison views, missing-data indicators and highlight details.

Open imports and accepts the plant image into the open project. Released marker gestures and valid coordinate, scale, visibility, inclusion and lock changes are retained without local Save controls. Apply to all is a validated batch edit. Closing PLOT keeps accepted changes; main Save writes image and geometry with the rest of the project. Zoom, opacity, captures and graph/CSV export retain their existing separate display/export roles.

Use CSV export for the applied saved-worker results. Summary graphs support their own settings and image export. The hidden legacy D3 experiment and unused plant transform metadata are not enabled by this migration.

Individual shows worker assessment symbols. Job shows one Job-risk square at each visible, positioned worker assignment: the same squares, sizes and positions as Comparison, without the individual symbol. Labels identify Jobs; a gray dashed square means no usable Job result. A Job can appear at several assignments. Job scope charts and the bottom Job average retain their placement-based aggregation; they are not an average of repeated map squares. Click the overview selector to search the applied workplace hierarchy, Job or worker IDs and names; choosing a leaf selects that exact assignment. Cancel retains the current selection.

Select, Zoom +, Zoom - and Pan are persistent map tools. The first rail button restores normal marker selection/movement. Magnifiers remain active across repeated clicks; Pan remains active across drags. Escape or right-click can also return to selection. There is no on-image instruction overlay. The image, worker symbols and Job squares magnify together at their original-image anchors. Wheel zoom, completed pan/middle drags, Fit image and marker opacity changes join the existing chronological Undo/Redo history. Tool choice and automatic resizing add no steps. Navigation history lasts for the open project session and does not require Save or write geometry. The plant image has no scrollbars. Maximum zoom is 400% of the fitted image. Zoom Out and Pan are disabled at fitted 100%; returning there restores the normal cursor if either tool was active. Both zoom-button tooltips show the current zoom percentage and maximum, including after Undo/Redo. Individual worker symbols have a dark outline. Locate recenters the zoomed view on the selected worker, clamping near image edges and retaining zoom. The recentering can be undone/redone without changing assignment geometry.

Job Overview includes a labeled Locate button beneath Current Job risk; it centers and highlights the selected Job square at the current zoom. The Job risk chart has one risk bar per Job, without placement-count suffixes. Squares on map in Job Overview counts the selected Job's visible repeated squares across the applied view. This count is separate from scoped Job placements and the existing placement-weighted summary. The Job record owns no map position or symbol scale; shared worker-assignment markers own them, with station anchors supplying initial positions where available.

In integrated Job view, Cancel movement restores the selected square's most recent accepted move in the current view. The restoration itself can be undone/redone. Pending typed coordinates can be discarded without replacing the accepted point. The panel reports the result; broader Undo remains available after changing views or reopening the window. Main Save writes accepted geometry changes.

JROT: guided rotations and optimization

Open JROT from the project toolbar or Tools menu. Create a named, dated rotation or select a saved one. Choose a Line and Shift, All Jobs or exact Workplace placements, participants and equal/unequal blocks. Copy Shift timing or edit the rotation's independent clock, breaks and averaging choice. Job means activity; Station means physical location.

Yes enters an existing baseline. No leaves the baseline absent: enter a proposal or generate a feasible initial proposal. Generation is not risk optimization. Review/edit shared Job tasks and risks, choose any one, two or all three tools, and optionally set worker restrictions and explicit neighboring runs. One worker occupies each selected position in each block.

Run optimization produces a preview. Keep optimization result explicitly retains it without changing the original baseline. Single-tool HiGHS first reduces the worst worker index, then balances the distribution without increasing that maximum. Multi-tool HiGHS uses the documented combined ceiling/spread objective. Tool tabs show one shared schedule, not separate solves. Review the qualified solver status, keep the result, then use Main Save. Undo restores the prior result. Cancel prevents application and waits safely for owned solver completion.

Comparison cards, statistics and optional matrices use frozen saved inputs and results. Worker indices are weighted Job-risk schedule measures, not individual assessments. Missing before schedules stay absent. Later Job edits mark older evidence stale rather than rewriting it. Reopen restores accepted results. Separate icon buttons provide advanced rework commands. Replacing the editable baseline requires confirmation; keeping a rerun confirms replacement of the prior result as an undoable edit. Shared Undo/Redo handles accepted edits. Reports remain unavailable pending their specification.

Settings → General → Compatibility → Show Legacy menu for this session exposes Legacy JROT for compatible older equal-block schemes. Guided scenarios cannot be edited/deleted there. Normal editing of an older scheme preserves unresolved date/timing until entered, then stores it as guided data. Legacy and Developer switches are independent, default off after restart, and are unnecessary for normal JROT. The temporary meeting prototype is retired.

Optimization runtime

All JROT optimizations use HiGHS directly, for one, two or all three tools. No solver-selection preference is needed. Existing kept results remain unchanged until you explicitly Keep a new result. Block minutes weight exposure; they do not prohibit a High Job in a long block. Every selected Job remains staffed in every block.

Copy/Move, exports and undo

Transfer selects saved current tools from the source assignment and an exact destination worker/workplace/shift. Copy retains the source; Move removes only the selected saved assessments after the entire transfer succeeds. Both preserve exact saved task inputs, results, units and recorded/fresh status. Existing selected destination tools require an explicit replacement warning with No as default; unrelated tools and historical observations remain. The source itself cannot be a destination. Other assessments, Job values and owners remain unchanged.

Copy/Move uses accepted project inputs and exact matching results, including unsaved project-session edits. Invalid, unaccepted field text is not copied. Transfer still requires its explicit record-operation confirmation, but never a separate project Save. Main Save publishes the resulting records together. CSV export reads accepted open-project data without saving it.

Main and editor Undo/Redo use the same chronological project history. One worker addition or accepted edit is one step; closing its window is not a step. Replay that removes records identifies them and requires confirmation, with Cancel as default. Cancellation consumes no step. Restoration and ordinary field/navigation changes need no removal warning. Focused fields keep typing Undo. Save preserves history; closing/switching projects ends it.

Backup, recovery and limitations

Before recovery, keep a separate copy of the current .ergprj file. Open a backup under a different name and check worker/context, all three tool results, PLOT image/markers and JROT schemes before continuing. Save As can make this verified backup your working copy. New-format projects contain all plant images and native data in one file, with one calculated result per assessment and no original archive; original XML projects still require their sidecars until conversion.

A failed Save retains the draft for correction or retry. Do not assume an error committed data; reopen a separate backup to inspect persisted state. Backups exclude unsaved edits and Undo histories. If Open/conversion fails, retain the originals and the error details; do not edit database rows blindly to bypass validation.

This milestone is validated on Linux XCB with approved exact dependency versions. Windows/macOS native acceptance is deferred. The scientific calculations preserve the original behavior, including documented metric moment and ST direction conventions; this migration is not a scientific revalidation. Hidden anthropometry prototypes remain only in the external original reference, not inside native projects or as validated tools.

The avatar colors all available tool regions for the selected worker and exact Job assignment/context; sidebar and camera focus follow the active tool.

Undo and Redo are the first two main-toolbar actions. PLOT and JROT have Undo/Redo buttons at the far right of their main title row, with the same shortcuts and editing history. Their separate Edit menu and history bar have been removed. Click a colored avatar region to select LiFFT (lower back), DUET (forearms/hands) or ST (shoulders). Neutral anatomy and background do nothing; dragging still rotates the avatar. Tool selection retains context and edits and uses the existing camera animation preference.

The main toolbar groups Undo/Redo, New/Open/Save, PLOT/JROT, and Organization/Jobs. Export is available in Project; Workplace contains Organization and Jobs. Project dialogs offer only .ergprj; an arbitrary SQLite database is not a valid ErgoTools project. Properties shows saved project details and is unavailable before the project is saved.

Accepted assessment tool, worker and workplace/context navigation remains ordered with data edits in shared project history. Valid DUET/ST choices and numeric edits remain reversible across worker/context changes. Invalid unfinished text stays available for correction. Task viewport restoration remains transient presentation state. Main Save writes the complete accepted project and retains its Undo/Redo branch.

Project Properties now shows only applicable single-file details: project name, filename, full location, recorded creation date/time, project language and measurement system, plus a complete scrollable description. Values are read-only and copyable; the dialog can be enlarged. Unknown optional metadata says Not recorded. Obsolete database/image/data sidecar folders are no longer displayed.

Assessment source Undo/Redo restores the horizontal and vertical scroll position captured when the edit began. For long grids, changing task 1 and undoing stays at task 1; edits in the middle return to that location even if you scroll away before replay. Qt focus is cleared from retiring controls before grid replacement, and scroll ranges update with row-count changes. This presentation state is session-local and never saved as scientific data.

Worker assignment Change and Remove retain historical assessment ownership. Add, Change and Remove accept valid worker/dropdown edits into the project session before operating; no local Save is required. Classification remains restricted to Jobs placed at the exact workplace and shift, and occupied destinations are rejected. Main Save writes these accepted changes. Workplaces counts station/shift placements, not Sections.

Assessment version creation and current-version selection have been removed. The Project menu retains New assessment and Assessment context. Each worker Job assignment and ergonomic tool has at most one saved assessment; Save updates that assessment. There are no New blank version or Set current version actions. Reassignment to another Job is a different assignment, not a second assessment version. Existing real task inputs/results remain linked to their original assignment.

Job values, task calculators and worker copies

Task inputs is the default for an empty tool; one blank starter row is shown without creating saved data. Use + Task and - Task to adjust the grid. Task names and Excel data

Each LiFFT, DUET and ST task can have an optional name. Type a name for that row, or select an existing reusable name from its list. To add a reusable name, choose Task names… → Add reusable name, then select it in the desired rows. Rename selected reusable name changes that name wherever it is used in this project. Typing over a selected name gives that row its own local name. Measurements remain independent even when rows share a name.

Click an input cell, then Shift-click another to highlight a rectangular range. Copy cells or Ctrl+C copies that range with headers and full precision. Escape or an ordinary input click clears the range. With no range selected, Copy cells copies all editable values and unit headers without rounding; ordinary text copy stays native. Paste uses the last compatible mapping for this tool; the small import button beside it always opens Import task data. Stage spreadsheet cells or CSV/TSV text, or open a CSV, TSV, TXT or XLSX file. For Excel, choose a worksheet and A1 range. Review headers, mapped fields, starting task, units and number format. The preview is editable; Validate preview checks without importing. Update preview after changing source text or interpretation choices.

Blank mapped cells clear values; unmapped fields stay unchanged. Loads are N or lbf, not kg. Invalid cells reject the whole paste; incomplete started rows are marked for completion. A successful paste is one Undo step and existing automatic calculation updates complete rows. Main Save stores assessment inputs.
