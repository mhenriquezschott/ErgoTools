# JROT scenario tutorials

Choose the example that matches your starting situation. Each PDF is independent
and follows the complete procedure from a new project to interpreting and keeping
an optimization result.

| Scenario | Tutorial | Pages |
|---|---|---:|
| You already use rotation and want to evaluate and optimize it | [Evaluate a current rotation](guides/jrot_tutorial_1_evaluate_current_rotation.pdf) | 103 |
| You want to revise a rotation already in use | [Change a current rotation](guides/jrot_tutorial_2_change_current_rotation.pdf) | 108 |
| You do not use rotation and want to explore it | [Explore introducing job rotation](guides/jrot_tutorial_3_explore_job_rotation.pdf) | 103 |

Each example explains project creation, the complete plant/section/line/station
hierarchy and shift, all worker records, reusable task names, all Job assessments,
rotation setup, optional restrictions, calculation checks, result interpretation
and saving. The contents and footer links navigate within that tutorial.

The examples also explain alternatives: adding workers or Jobs while inside JROT,
using all project records or a workplace scope, and using a Shift timing template
or defining timing for the rotation. They use the implemented weighted Job-risk
indices and distinguish those indices from workers' individual assessments.

Use the [complete illustrated user guide](guides/ergotools_user_guide.pdf) for the
broader ErgoTools, PLOT, JROT and Settings interfaces. For installation, updates
and bug reports, use the [installation and GitHub guide](guides/ergotools_installation_and_github_guide.pdf).
