from pathlib import Path

root = Path.cwd()
docs = root / 'docs'
addition = '''
## Open a project from the command line

The original positional-project convention is supported:

```bash
bash tools/run.sh "artifacts/m10-integration-final/run/M10-validated.ergprj"
```

From an independent installation, use `ergotools "/absolute/path/project.ergprj"`.
Quote paths containing spaces. Relative paths are relative to the terminal's
current directory, even when the launcher script lives elsewhere. The normal
assessment-selection and original-project conversion dialogs still apply;
startup does not automatically Save. Successful opens enter Project > Recent
projects (Proyecto > Proyectos recientes), up to ten paths, newest first.
Cancelled or failed opens are not added. Clear History removes only menu history.

The comprehensive converted fixture above includes assessment, PLOT and JROT
data and integration-test edits. `M10-backup.ergprj` beside it is its saved backup.
Use Save As for a personal review copy. The similarly named XML original-project
descriptor in that folder is a copied conversion input, not the converted file.
'''
p = docs / 'linux-delivery.md'
p.write_text(p.read_text() + addition)
(root / 'dist/linux/INSTALL.md').write_text(p.read_text())
for filename in ('user-guide.md', 'development.md'):
    p = docs / filename
    p.write_text(p.read_text() + addition)
p = docs / 'user-guide-es.md'
p.write_text(p.read_text() + '''
## Abrir un proyecto desde la terminal

Ejecute `bash tools/run.sh "/ruta/al/proyecto.ergprj"` desde el proyecto nuevo,
o `ergotools "/ruta/al/proyecto.ergprj"` en una instalación independiente.
Use comillas si la ruta contiene espacios. Se utiliza el flujo normal de apertura,
selección de evaluación y conversión; no se guarda automáticamente.
Proyecto > Proyectos recientes recuerda hasta diez aperturas correctas.
Cancelar o fallar no añade entradas; borrar el historial no elimina proyectos.
''')
for language, paragraph in (
    ('en', '<p>Open a project from the terminal with <code>bash tools/run.sh "/path/project.ergprj"</code>, or <code>ergotools "/path/project.ergprj"</code> after independent installation. Quote paths containing spaces. Normal assessment selection/conversion applies; startup does not Save automatically. Project &gt; Recent projects remembers up to ten successful opens. Clear History removes only history, not project files.</p>'),
    ('es', '<p>Abra un proyecto desde la terminal con <code>bash tools/run.sh "/ruta/proyecto.ergprj"</code>, o <code>ergotools "/ruta/proyecto.ergprj"</code> en una instalación independiente. Use comillas si la ruta contiene espacios. Se aplica la selección/conversión normal; no se guarda automáticamente. Proyecto &gt; Proyectos recientes recuerda hasta diez aperturas correctas. Borrar historial no elimina archivos de proyectos.</p>'),
):
    p = root / f'src/ergotools/resources/documents/user-guide-{language}.html'
    s = p.read_text()
    assert '</header>' in s
    p.write_text(s.replace('</header>', '</header>' + paragraph, 1))
with (root / 'AGENTS.md').open('a') as stream:
    stream.write('''

After closure the owner identifies the original positional command-line project
workflow as missing and reaffirms Recent Projects. Restore that bounded original

under Project in EN/ES and retains ten successful locations. Reference stays
read-only. Record correction evidence in docs/cli-project-acceptance.md.
''')
print('CLI and Recent Projects instructions updated in Markdown and packaged EN/ES Help.')
