# Documentation images

These are actual Linux Qt/XCB screenshots of the application, using private copies
of example projects. Main assessment captures include the rendered VTK anatomy.
No screenshot establishes native Windows or macOS deployment acceptance.

## Public overview

- `ergotools_lifft.png`, `ergotools_duet.png`, `ergotools_shoulder.png`: the three
  assessment workspaces, illustrating low, intermediate and high modeled risk.
- `assessment_avatar.png`, `assessment_risk_panel.png`: focused anatomy/results views.
- `worker_management.png`, `worker_assignments.png`, `organization_management.png`:
  worker records and the workplace hierarchy.
- `assessment_workplace.png`, `main_assigned_assessment.png`: selected workstation
  assessment and its location in the main workspace.
- `job_assessment_editor.png`: current shared Job task editor and risk summaries.
- `find_assessment.png`, `transfer_assessment.png`: assessment search and reuse.
- `plot_*`: map modes, individual/Job/comparison gauges and population charts.

The published JROT README illustrations and descriptions are intentionally retained.
`job_management.png` belongs to that retained set; the current Job editor uses the
separate `job_assessment_editor.png` image. The `jrot_guided_*` images document the
current guided interface in component documentation rather than replacing that
public overview.

## Component illustrations

`task_columns.png`, `task_names.png`, `shift_rotation_timing.png`, `settings_*.png`
and `import_row_selection.png` illustrate the corresponding technical guides.
Settings previews use explicitly illustrative values. The avatar animation is a
packaged recording of the real model and existing camera paths; Settings does not
instantiate another VTK renderer.

## Capture conventions

Use disposable sample identities and private project copies; keep maintained project
files unchanged. Capture real, populated native windows and inspect text, icons,
expanded states and bottom actions before cropping. Preserve proportions and readable
text. Trim to the described region without hiding context required to interpret it.
Keep original full-resolution evidence locally; do not publish private worker data.
