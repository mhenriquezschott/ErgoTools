# Documentation images

This directory contains the screenshots displayed by the repository README.

The screenshots are generated from the current UI using the `test3` sample project. To replace an image, keep its existing filename so links from the README continue to work.

`assessment-workspace.png` is intentionally cropped around the assessment and result panels because automated UI capture runs without the production VTK renderer. It can be replaced with a full application capture that includes the rendered anatomical model.
