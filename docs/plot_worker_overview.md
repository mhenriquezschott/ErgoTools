# PLOT Worker Overview

The overview identifies the selected worker's exact assessment assignment, workplace,
shift and optional Job. It displays available demographic information, the active tool's
saved assessment values and applicable Job values without merging their meanings.
Zero and missing results remain distinct. Current Job values come from one set per Job/tool;
there is no profile/evidence lifecycle selector.

The hierarchy-aware selection control opens the shared searchable result picker. Selecting
another worker does not move that worker. Locate reveals and centers a saved marker in a
zoomed map where possible. Marker preview and visual controls reflect the selected
assignment's point, visibility, enabled/locked state and scale. Unplaced points are not
fabricated. Cancel movement restores the saved point; accepted changes enter shared
history and main Save.

Individual and Comparison retain worker-focused information; Job view uses Job Overview
for the assignment square. See [selection](plot_worker_search.md),
[markers](plot_marker_rendering.md) and [map controls](plot_map_controls.md).
