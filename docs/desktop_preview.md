# Retired preview instructions

For the current integrated application run:

```bash
.venv/bin/python -m ergotools.bootstrap --integrated-preview
```

Use [development](development.md), [user guide](user_guide.md) or
[guía en español](user_guide_es.md). The flag name is retained for CLI compatibility;
it selects the integrated application with VTK, all assessments, PLOT and JROT.

The no-flag LiFFT component and separate Job Management demo are development
harnesses, not the intended final UI. Historical preview limitations/instructions
are archived in desktop_preview_checkpoint_history.md. Do not follow them to
decide current functionality or project compatibility.
